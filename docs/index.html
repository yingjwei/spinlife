spinlife — VASP PROCAR 自旋寿命计算流水线

从 VASP 非共线 (LSORBIT) 计算的 PROCAR 文件出发, 解析自旋密度矩阵, 提取 SOC 参数 α, β, 计算自旋寿命 τs 和 PSH 周期 LPSH.

流水线总览

PROCAR → read_procar.py 解析 k 点/能带/自旋 → fit_soc.py 拟合 α, β, τs → 输出: 报告 + 图形

一、PROCAR 格式详解 (逐行操作说明)

从 tot 行到自旋期望值的物理

VASP 在非共线计算中输出的自旋密度矩阵为: 

ρ(k) = ρ₀(k) · I + m_x(k) · σ_x + m_y(k) · σ_y + m_z(k) · σ_z

其中 ρ₀ = tot(块1) 是电荷密度, mᵢ = tot(块2-4) 是磁化密度的三个分量。 read_procar.py 的 第98-101行 从中计算自旋期望值: 

⟨σ_x⟩ = m_x / ρ₀    → 用于 fit_soc.py 第44-54行: 确定 α/β 比值
⟨σ_y⟩ = m_y / ρ₀    → 用于 fit_soc.py 第44-54行: 确定 α/β 比值
⟨σ_z⟩ = m_z / ρ₀    → 用于评估 PST 质量 (偏离角 δθ)
注意: VASP 的 tot 行 最后一列 是各轨道投影的 总和 (即该 tot 值). 脚本用 float(tot_parts[-1]) 提取它.

三、物理方法概述

有效质量 m*

抛物线近似: E(k) = E₀ + ℏ²(k-k₀)² / (2m*)
对 E vs (k-k₀)² 做线性回归, 斜率 A, 则 m*/m₀ = 3.81 / |A|.

自旋-轨道耦合参数 α, β

对于 PST 体系 (如 C2y 对称性): 

H(k) = [Δ + ℏ²k_x²/(2m*)]σ_z + αk_xσ_x + βk_xσ_y

能带劈裂: ΔE = 2√[Δ² + (α²+β²)k_x²] → ΔE² = 4Δ² + 4(α²+β²)k_x² → 线性拟合得 √(α²+β²) 和 Δ.

自旋期望值 (k→0): ⟨σ_x⟩ = 2αk_x/Δ, ⟨σ_y⟩ = 2βk_x/Δ → α/β = ⟨σ_x⟩/⟨σ_y⟩ → 结合 √(α²+β²) 分离 α, β.

自旋寿命 τ_s

D'yakonov-Perel (DP) 机制主导: 

τ_s ≈ ℏ² / (2 m* α_eff² τ_p)

其中 α_eff = |α − β|. 当 α ≈ β (SU(2) 对称性), τ_s 发散 → PST 的长自旋寿命特性.

四、用法示例

# 基本用法 (自动检测 VBM)
python -m spinlife.main PROCAR

# 指定 VBM band 和拟合参数
python -m spinlife.main PROCAR --vbm 400 --tau-p 0.5 --k-range 0.03 --T 300

# 查看帮助
python -m spinlife.main --help

六、注意事项

  • PROCAR 必须来自 LSORBIT 计算: 否则没有 4 个自旋密度块
  • k 网格必须是均匀的: 目前脚本假设 k 点构成 2D 矩形网格
  • τ_p 需要外部输入: 动量散射时间需从实验或 AMSET/PERTURBO 计算
  • 简化模型: 自旋寿命计算基于 DP 机制的简化公式, 完整自旋扩散方程求解待后续扩展
