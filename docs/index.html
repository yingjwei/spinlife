spinlife — VASP 自旋寿命 + 载流子迁移率计算

解析 VASP LSORBIT PROCAR, 提取 SOC 参数 α, β, 计算自旋寿命 τs、PSH 周期 LPSH 和载流子迁移率 μ.

两个子命令: python -m spinlife.main PROCAR — 自旋寿命 (PROCAR 直接读)
python -m spinlife.main mobility — 载流子迁移率 (交互式输入)

一、这个代码做了什么计算

以下按计算流程逐个说明每个物理量的定义、公式和代码实现, 方便用户手算验证.

1.1 有效质量 m*

代码: fit_soc.py 第27-49行, fit_effmass()

沿 ky=0 切面取 VBM/CBM 附近 k 点, 做抛物线拟合:

E(k) = E₀ + A(k-k₀)²

对 (k-k₀)² vs E 线性回归 → 斜率 A
m*/m₀ = 3.81 / |A|
系数 3.81 的由来: ℏ²/(2m₀) = (6.582×10⁻¹⁶ eV·s)² / (2 × 9.109×10⁻³¹ kg × 10⁻²⁰ m²/Å²) = 3.81 eV·Å². 即 E(eV) = 3.81 · k²(Å⁻²) / (m*/m₀).

1.2 自旋-轨道耦合参数 √(α²+β²)

代码: fit_soc.py 第52-80行, fit_alpha_beta()

从 SOC 劈裂的双带出发 (如 VBM/VBM-1), 提取能带劈裂 ΔE = |E_upper - E_lower|:

ΔE² = 4Δ² + 4(α²+β²)k²

对 k² vs ΔE² 线性回归:
  slope = 4(α²+β²)
  intercept = 4Δ²

√(α²+β²) = √(slope) / 2       (单位: eV·Å)
Δ = √(intercept) / 2           (单位: eV)

1.3 α/β 比值分离

代码: main.py 第168-189行 (自旋织构线性拟合)

从 k·p 模型, 自旋期望值在 k→Γ 附近:

⟨σ_x⟩ ≈ 2αk/Δ      ⟨σ_y⟩ ≈ 2βk/Δ

→ ⟨σ_x⟩/⟨σ_y⟩ = α/β   (k 无关, 仅由 SOC 系数比决定)

对 ⟨σ_x⟩ vs k 线性回归 → slope_x
对 ⟨σ_y⟩ vs k 线性回归 → slope_y

ratio = slope_x / slope_y   (= α/β)

α = √(α²+β²) / √(1 + 1/ratio²)
β = α / ratio
验证方法: 用 --dump-band N 导出能带原始数据 (k, E, ⟨σ_x⟩, ⟨σ_y⟩, ⟨σ_z⟩), 在 Excel 或 Origin 中手动做两次线性拟合, 与程序结果对比: 
python -m spinlife.main PROCAR --dump-band 44
输出 band_44_data.txt, 包含 k(Å⁻¹), E(eV), ⟨σ_x⟩, ⟨σ_y⟩, ⟨σ_z⟩.

1.4 自旋寿命 τ_s (DP 机制)

代码: fit_soc.py 第103-158行, calc_spin_lifetime()

α_eff = |α - β|                         (SU(2) 对称性破缺项)
α_eff_Jm = α_eff × 1e-3 × e × 1e-10     (meV·Å → J·m)

τ_s = ℏ² / (2 × m* × m₀ × α_eff_Jm² × τ_p)    (秒)

L_PSH = πℏ² / (m* × m₀ × |α|_Jm)              (米)
      ≈ 2.39 / (m* × |α|_meVA)                 (μm)

1.5 弹性模量 C₂D

代码: mobility/calc_mobility.py, fit_C2D()

对不同晶格应变的总能量做二次拟合:

E(ε) = E₀ + A₁ε + A₂ε²

∂²E/∂ε² = 2A₂                                (eV)
C₂D = (1/A₀) × ∂²E/∂ε²                       (eV/Å²)
C₂D (J/m²) = C₂D (eV/Å²) × e / 10⁻²⁰         (J/m²)

应变计算:

  1. 对 a 或 b 晶格做 ±1%, ±2%, ±3% 的缩放 (固定另一轴)
  2. 每个应变点做 relax (ISIF=2) + SOC static 计算
  3. 从 relax OUTCAR 读总能量, 从 SOC OUTCAR 读 VBM/CBM 能量
  4. A₀ = a × b (平衡晶格面积, 从 POSCAR 读取)
注意事项:
  • INCAR 中 ICHARG=2 在 relax 中仍然做完整 SCF, 可以安全使用
  • 至少 5 个应变点 (±1%, ±2%, 0%) 才能获得可靠的二次拟合
  • x 和 y 方向各跑一组应变, 分别得到 C₂Dx 和 C₂Dy

1.6 形变势常数 E₁

代码: mobility/calc_mobility.py, fit_E1()

对 VBM/CBM 能量随应变的变化做线性拟合:

E_VBM(ε) = E₀ + E₁ · ε

E₁ = slope          (eV)

E₁ 反映能带边缘对晶格变形的敏感度: E₁ 越大, 电子-声子散射越强, 迁移率越低.

1.7 载流子迁移率 μ

代码: mobility/calc_mobility.py, calc_mu()

2D 形变势理论公式 (Bardeen-Shockley 推广):

μ = (2 e ℏ³ C₂D) / (3 k_B T |m*|² E₁²)

其中:
  e  = 1.602×10⁻¹⁹ C     (元电荷)
  ℏ  = 1.055×10⁻³⁴ J·s  (约化普朗克常数)
  k_B = 1.381×10⁻²³ J/K  (玻尔兹曼常数)
  C₂D: J/m²               (弹性模量)
  m*: kg                  (有效质量)
  E₁: J                   (形变势常数)
  T: K                    (温度)

输出: cm²/V·s

二、这个代码如何使用

2.1 安装

pip install -e .
# 或
pip install git+https://github.com/yingjwei/spinlife.git

2.2 子命令 1: 自旋寿命 (PROCAR)

输入 VASP LSORBIT 计算的 PROCAR 文件, 自动提取 α, β, τ_s.

两种运行方式: python -m spinlife.main PROCAR (模块模式, 需安装) 或 python /path/to/spinlife/main.py PROCAR (直接执行) 
# vaspkit 风格交互 — 显示能带表, 输入 SOC 带对
python -m spinlife.main PROCAR

# 先导出能带原始数据, 手算验证
python -m spinlife.main PROCAR --dump-band 44

# 命令行指定 SOC 带对 (跳过交互式输入)
python -m spinlife.main PROCAR --soc-vbm 44 43 --soc-cbm 45 46

# 指定 VBM band 和拟合参数
python -m spinlife.main PROCAR --vbm 44 --tau-p 0.5 --k-range 0.03 --T 300

# 查看帮助
python -m spinlife.main --help

2.5 完整的迁移率计算流程

  1. 用 spinlife 算 m*: python -m spinlife.main PROCAR (记录 m* 值)
  2. 跑应变 batch: x 方向 (拉伸 a) 和 y 方向 (拉伸 b) 各一组, 每组 ±1%, ±2%, ±3% 共 7 个应变点
  3. 提取数据: 从 relax OUTCAR 读总能量, 从 SOC OUTCAR 读 VBM/CBM
  4. 算迁移率: python -m spinlife.main mobility, 按提示输入数据

2.6 INCAR 示例 (应变计算)

Relax (每个应变点)Static (SOC)
ISIF2—
IBRION2-1
NSW10000
ICHARG22
LSORBIT—.TRUE.

每个应变点: 修改 POSCAR 的 a 或 b 晶格 → relax → 重跑 SOC static 两个 VASP 任务.
