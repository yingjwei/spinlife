spinlife — VASP 自旋寿命 + 载流子迁移率计算

解析 VASP LSORBIT PROCAR 和 Wannier90 能带, 提取 SOC 参数 α, β, 有效质量 m*, 自旋寿命 τs, PSH 周期 LPSH 和载流子迁移率 μ.

安装后直接启动: spinlife
或 (未安装): python -m spinlife.main

结果在模块之间自动传递: 选项 2/3/1 → 4 无需重新输入
所有输出文件 (报告/图片/数据) 统一保存在当前目录下的 spinlife/ 文件夹
快捷命令 (向后兼容): spinlife PROCAR spinlife mobility

一、功能列表

 ========================================================================
  spinlife — VASP 自旋寿命 + 载流子迁移率计算
 ========================================================================

  1)  载流子迁移率 (Mobility)
  2)  有效质量 (Wannier 能带 → m*)
  3)  SOC 参数 α/β (Wannier + PROCAR)
  4)  自旋寿命 (结果整合 — 自动装载上下文)
  5)  导出能带数据
  6)  生成 KPOINTS 文件 (Wannier → k₀ → 网格)

  0)  退出

选项 1: 应变-总能量 → C₂D, E₁, μ, τp (x + y 双方向, 各向异性 m*)

选项 2: 读 wannier90_band.dat → 抛物线拟合 → m* (密 k 网格, 可靠)

选项 3: Wannier 自动扫描 Δk: ΔE² vs k² 独立选最优 → √(α²+β²); 抛物线独立选最优 → m* (与选项 2 统一); PROCAR Γ 点直接做比 → α/β 比值

选项 4: 整合前三步结果, 自动装载已知的 m*, α, β, τp → τs, LPSH

选项 6: 读 Wannier 能带 → 选 SOC 带对 → 自动定位 k₀ → 各方向独立设置密度 → 生成 KPOINTS

二、计算方法

2.1 有效质量 m*

数据来源: Wannier90 能带 (wannier90_band.dat, 密 k 网格)

在能带极值 (VBM / CBM) 附近做抛物线拟合:

E(k) = E₀ + A (k − k₀)²
对 (k − k₀)² 与 E 做线性回归 → 斜率 A
m* / m₀ = 3.81 |A|
其中 3.81 = ℏ²/(2m₀), 单位 eV·Å²

需提供晶格常数 a (Å) 将 Wannier90 分数坐标 k 转换为 Å⁻¹.

2.2 √(α²+β²) — Wannier SOC 能带

数据来源: Wannier90 SOC 双带 (含自旋-轨道耦合)

Rashba 模型下, SOC 劈裂能 ΔE 与波矢 k 的关系:

ΔE = |Eupper − Elower|
ΔE² = 4Δ² + 4(α² + β²) k²
对 k² 与 ΔE² 做线性回归:
斜率   = 4 (α² + β²)
截距   = 4Δ²
√(α² + β²) = √(斜率) / 2    (eV·Å)
Δ = √(截距) / 2    (eV)

同时自动扫描有效质量 m*: Wannier 密 k 网格对 Eup 做抛物线拟合, 与 √(α²+β²) 各自独立扫描最优 Δk, 与选项 2 统一.

Wannier 密 k 网格提供几百个 k 点, 拟合可靠性远超 VASP 稀疏 k 网格.

2.3 α/β 比值 — PROCAR Γ 点直接做比

数据来源: VASP LSORBIT PROCAR (Γ 附近自旋分量)

从 k·p 模型, 在一阶近似下:

⟨σx⟩ / ⟨σy⟩ = α / β
比值与 k 无关 (k·p 一阶近似). 在 Γ−X 方向切片中, 找离 Γ 最近且自旋信号可靠 (|Sx|, |Sy| > 10⁻³) 的 k 点:

此法无需拟合范围, 只需 1 个可靠 k 点即可得到 α/β.

自动排除 Γ 点 (SOC 劈裂 Δ → 0, 自旋发散), 无需拟合范围, 无需手工选择.

2.4 自旋寿命 τs (DP 机制)

D'yakonov–Perel (DP) 机制下, 自旋寿命由 α 和 β 的 SU(2) 对称性破缺决定:

αeff = |α − β|
SU(2) 对称性破缺项 — 决定自旋退相位速率
τs = ℏ² 2 · m* · m₀ · αeff² · τp

PSH (Persistent Spin Helix) 周期:

LPSH = πℏ² m* · m₀ · |α|
≈ 2.39 / (m* · |α|meV·Å)    (单位 μm)

τs 由选项 2 和 3 的结果输入计算. τp 可直接输入, 或用 μ 反算:

τp = μ · m* / e

2.5 载流子迁移率 μ

数据来源: VASP 应变计算 (relax OUTCAR 总能量 + SOC OUTCAR 能带边缘)

基于二维形变势理论:

C2D = (1 / A₀) × ∂²E / ∂ε²
弹性模量 — 应变-总能量二次拟合 (J/m²)
E₁ = dEVBM / dε   或   dECBM / dε
形变势 — 能带边缘线性拟合 (eV)
μ = 2eℏ³C2D 3kBT |m*|² E₁²
单位: cm²/V·s
τp = μ · m* / e
动量散射时间 (ps)

支持 x + y 双方向一次运行, m*x ≠ m*y 各向异性.

三、使用指南

3.1 交互式菜单

python -m spinlife.main

默认进入 vaspkit 风格交互菜单, 按数字选择功能.

3.2 Wannier 有效质量

--> 选择 2) 有效质量
--> 输入 wannier90_band.dat 路径
--> 输入晶格常数 a (Å)
--> 选择能带序号
--> 选择 VBM/CBM

m* = 4.3210 m₀  (R² = 0.9998)

3.3 SOC α/β

--> 选择 3) SOC 参数 α/β

[1/2] Wannier SOC 能带 → √(α²+β²) + m*
  -->  输入 wannier90_band.dat
  -->  选择 SOC 带对上/下能带
  (自动扫描最优 Δk 拟合范围)

[2/2] PROCAR → α/β 比值 (Γ 点直接做比, 无需拟合)
  -->  输入 PROCAR 路径
  -->  指定 SOC 带对

√(α²+β²) = 14.13 meV·Å
α/β     = 1.234
α       = 11.23 meV·Å
β       = 9.10 meV·Å

3.4 快捷命令行 (向后兼容)

# PROCAR 传统模式 (PROCAR 稀疏 k 网格)
python -m spinlife.main PROCAR
python -m spinlife.main PROCAR --soc-vbm 44 43 --soc-cbm 45 46
python -m spinlife.main PROCAR --dump-band 44

# 迁移率
python -m spinlife.main mobility

# KPOINTS 生成
python -m spinlife.genkpoints [kx ky kz]

# 直接执行
python /path/to/spinlife/main.py

3.5 完整工作流 (结果自动传递)

程序采用会话状态 (session context) 设计: 选项 1/2/3 的计算结果自动保存在内存中, 菜单顶部实时显示当前已知量. 进入选项 4 时, 所有已知结果自动预填入输入提示.

  1. 有效质量 (选项 2) → 读 wannier90_band.dat, 存 m*
  2. SOC α/β (选项 3) → Wannier + PROCAR, 存 α, β
  3. 迁移率 (选项 1) → 应变计算, 存 μ, τp, T
  4. KPOINTS (选项 6) → 读 Wannier 能带, 选 SOC 带对, 生成密集 k 网格
  5. 自旋寿命 (选项 4) → 自动装载上述所有结果, 一键算出 τs, LPSH
可选: 也可只运行部分步骤, 选项 4 自动识别缺失项并要求手工输入. 例如只做了 Wannier m* 和 SOC α/β, τp 可以在选项 4 中直接输入或通过 μ 反算.
