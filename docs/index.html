spinlife -- VASP 自旋寿命 + 载流子迁移率计算

解析 VASP LSORBIT PROCAR 和 Wannier90 能带, 提取 SOC 参数 alpha, beta, 有效质量 m*, 自旋寿命 tau_s, PSH 周期 L_PSH 和载流子迁移率 mu.

安装后直接启动: spinlife
或 (未安装): python -m spinlife.main

结果在模块之间自动传递: 选项 2/3/1 到 4 无需重新输入
所有输出文件 (报告/图片/数据) 统一保存在当前目录下的 spinlife/ 文件夹
快捷命令 (向后兼容): spinlife PROCAR spinlife mobility

一、功能列表

 ========================================================================
  spinlife -- VASP 自旋寿命 + 载流子迁移率计算
 ========================================================================

  1)  载流子迁移率 (Mobility)
  2)  有效质量 (Wannier 能带 -> m*)
  3)  SOC 参数 alpha/beta (Wannier 能带平均法 + PROCAR 诊断)
  4)  自旋寿命 (结果整合 -- 自动装载上下文)
  5)  导出能带数据
  6)  生成 KPOINTS 文件 (Wannier -> k0 -> 网格)

  0)  退出

选项 1: 应变-总能量 -> C2D, E1, mu, tau_p (x + y 双方向, 各向异性 m*)

选项 2: 读 wannier90_band.dat -> 抛物线拟合 -> m* (密 k 网格, 可靠)

选项 3: Wannier SOC 双带 -> 能带平均法同步拟合 m* + sqrt(alpha^2+beta^2); PROCAR 自旋 -> alpha/beta 比值 (诊断, 可选)

选项 4: 整合前三步结果, 自动装载已知的 m*, sqrt(alpha^2+beta^2), tau_p -> tau_s, L_PSH

选项 6: 读 Wannier 能带 -> 选 SOC 带对 -> 自动定位 k0 -> 各方向独立设置密度 -> 生成 KPOINTS

二、计算方法

2.1 有效质量 m*

数据来源: Wannier90 能带 (wannier90_band.dat, 密 k 网格)

E(k) = E0 + A(k-k0)^2

对 (k-k0)^2 vs E 线性回归 -> 斜率 A
m*/m0 = 3.81 / |A|        (3.81 = hbar^2/2m0 in eV.A^2)

需提供晶格常数 a (A) 将 Wannier90 分数坐标 k 转换为 A^-1.

2.2 sqrt(alpha^2+beta^2) + m* -- 能带平均法 (推荐)

数据来源: Wannier90 SOC 双带 (含自旋-轨道耦合)

传统 DeltaE^2 vs k^2 拟合方法对噪声敏感 (平方操作放大误差). spinlife 使用能带平均法, 信噪比提升 ~10 倍.

Rashba 哈密顿量 SOC 劈裂带:

E_+(k) = E0 + A(k-k0)^2 + sqrt(alpha^2+beta^2)*|k-k0|
E_-(k) = E0 + A(k-k0)^2 - sqrt(alpha^2+beta^2)*|k-k0|

步骤 1 -- 带平均 -> 有效质量:

E_avg = (E_upper + E_lower) / 2 = E0 + A(k-k0)^2
对 (k-k0)^2 vs E_avg 线性回归 -> A -> m*

线性 SOC 项 (+/- sqrt(alpha^2+beta^2)k) 在平均后恰好抵消, 回归残差即为抛物线拟合质量.

步骤 2 -- 带差 -> sqrt(alpha^2+beta^2):

|E_upper - E_lower| / 2 = sqrt(alpha^2+beta^2)*|k-k0|
对 |k-k0| vs |E_up-E_lo|/2 线性回归 -> 斜率 = sqrt(alpha^2+beta^2)

步骤 3 -- 迭代降噪: 自动计算 k 点残差, 剔除噪声点后重新拟合, 迭代至收敛.

优势总结:

  • sqrt(alpha^2+beta^2) 信噪比 ~10x 优于 DeltaE^2 法 -- 避免平方放大噪声
  • m* 和 sqrt(alpha^2+beta^2) 同时获得, 无需额外有效质量拟合步骤
  • 迭代式噪声过滤确保拟合稳定性

2.3 alpha/beta 比值 -- PROCAR 自旋期望 (诊断)

数据来源: VASP LSORBIT PROCAR (Gamma 附近自旋分量)

从 k.p 一阶近似, = 2*alpha*k/Delta, = 2*beta*k/Delta, 故在任意非 Gamma k 点处:

 /  = alpha / beta    (比值与 k 无关)

Gamma 点直接做比: 程序遍历 SOC 双带, 取 Gamma 附近最近邻且 |Sx|,|Sy| > 1e-3 的 k 点, 直接计算 Sx/Sy 作为 alpha/beta. 这避免了多 k 点线性拟合中不同方向自旋响应混合导致的失真.

面外 PST 体系中 PROCAR 自旋期望值极小 (~0.001). 程序自动评估:

  • 比值稳定 (1e-6 < |ratio| < 1e6): 用于 alpha/beta 分离和 L_PSH 计算
  • 比值不稳定: 自动跳过, 但 tau_s 仍可通过 sqrt(alpha^2+beta^2) 估算

2.4 自旋寿命 tau_s (DP 机制)

tau_s = hbar^2 / (2 * m* * m0 * (alpha^2+beta^2) * tau_p)

L_PSH = 2.39 / (m* * |alpha|)     (um, 需 PROCAR 自旋织构比值稳定)

tau_s 由选项 2 + 3 的结果计算: m* 来自带平均抛物线拟合, (alpha^2+beta^2) 来自带差线性拟合. L_PSH 需要 alpha/beta 比值 (来自 PROCAR 拟合, R^2>=0.5). tau_p 可直接输入, 或用 mu 反算 (tau_p = mu * m* / e).

2.5 载流子迁移率 mu

数据来源: VASP 应变计算 (relax OUTCAR 总能量 + SOC OUTCAR 能带边缘)

C2D = (1/A0) * d^2E/de^2             (弹性模量, J/m^2)
E1  = dE_VBM/de 或 dE_CBM/de          (形变势, eV)

mu = 2e*hbar^3*C2D / (3*kB*T*|m*|^2*E1^2)   (cm^2/V*s)
tau_p = mu * m* / e                          (动量散射时间, ps)

支持 x + y 双方向一次运行, m*_x != m*_y 各向异性.

三、使用指南

3.1 交互式菜单

python -m spinlife.main

默认进入 vaspkit 风格交互菜单, 按数字选择功能.

3.2 Wannier 有效质量

--> 选择 2) 有效质量
--> 输入 wannier90_band.dat 路径
--> 输入晶格常数 a (A)
--> 选择能带序号
--> 选择 VBM/CBM

m* = 4.3210 m0  (R^2 = 0.9998)

3.3 SOC alpha/beta

--> 选择 3) SOC 参数 alpha/beta

[1/1] Wannier SOC 能带 -> sqrt(alpha^2+beta^2) + m* (能带平均法)
  -->  输入 wannier90_band.dat
  -->  选择 SOC 带对上/下能带
  -->  拟合范围 +/- Delta k

sqrt(alpha^2+beta^2) = 14.13 meV.A
m*                   = 4.32 m0

[可选] PROCAR -> alpha/beta 比值诊断
  -->  输入 PROCAR 路径
  -->  指定 SOC 带对
  -->  自动判定 R^2 质量阈值

3.4 快捷命令行 (向后兼容)

# PROCAR 传统模式 (PROCAR 稀疏 k 网格)
python -m spinlife.main PROCAR
python -m spinlife.main PROCAR --soc-vbm 44 43 --soc-cbm 45 46
python -m spinlife.main PROCAR --dump-band 44

# 迁移率
python -m spinlife.main mobility

# KPOINTS 生成
python -m spinlife.genkpoints [kx ky kz]

# 直接执行
python /path/to/spinlife/main.py

3.5 完整工作流 (结果自动传递)

程序采用会话状态 (session context) 设计: 选项 1/2/3 的计算结果自动保存在内存中, 菜单顶部实时显示当前已知量. 进入选项 4 时, 所有已知结果自动预填入输入提示.

  1. 有效质量 (选项 2) -> 读 wannier90_band.dat, 存 m*
  2. SOC alpha/beta (选项 3) -> Wannier 能带平均法, 存 sqrt(alpha^2+beta^2), m*; PROCAR 选做, 存 alpha, beta
  3. 迁移率 (选项 1) -> 应变计算, 存 mu, tau_p, T
  4. KPOINTS (选项 6) -> 读 Wannier 能带, 选 SOC 带对, 生成密集 k 网格
  5. 自旋寿命 (选项 4) -> 自动装载上述所有结果, 一键算出 tau_s, L_PSH
可选: 也可只运行部分步骤, 选项 4 自动识别缺失项并要求手工输入. 例如只做了 Wannier m* + sqrt(alpha^2+beta^2), tau_p 可以在选项 4 中直接输入或通过 mu 反算.
